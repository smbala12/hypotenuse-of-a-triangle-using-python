# 📐 Hypotenuse Calculator (Python)

A simple Python program that calculates the **hypotenuse of a right triangle** using user-provided side lengths.

---

## 📌 How It Works

The program:

1. Imports the built-in `math` module.
2. Prompts the user to enter the two shorter sides of a right triangle (`a` and `b`).
3. Uses the Pythagorean Theorem to calculate the hypotenuse.
4. Rounds the result to 2 decimal places.
5. Displays the hypotenuse with units.

---

## 🧮 Formula Used

The Pythagorean Theorem:

c = √(a² + b²)

Where:
- `a` = first side
- `b` = second side
- `c` = hypotenuse
